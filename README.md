①   若继承⽅式是public，基类成员在派⽣类中的访问权限保持不变，也就是说，基类中的成
员访问权限，在派⽣类中仍然保持原来的访问权限；
②  若继承⽅式是private，基类所有成员在派⽣类中的访问权限都会变为私有(private)权限；
③  若继承⽅式是protected，基类的共有成员和保护成员在派⽣类中的访问权限都会变为保护
(protected)权限，私有成员在派⽣类中的访问权限仍然是私有(private)权限
